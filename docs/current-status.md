## 账号协议配置

账号协议类型新增“多模态”，新账号及空白映射默认使用 multimodal 模型类型，支持独立筛选、编辑、发现后添加映射及默认测试模型。复用 OpenAI Completions / Responses / Anthropic Messages 协议路径，实际图片、音频或视频能力以模型及上游协议支持为准。原有文本账号的多模态映射保持兼容，不自动改变历史配置。模型组仍按文本推理协议归类；文本内容合规策略适用时不接受非文本输入。

新增、编辑账号支持 openai-completions、openai-responses、anthropic-messages 多选及独立路径前缀，Anthropic 支持 x-api-key / Bearer Token。服务 URL 与路径前缀拼接后追加固定协议端点；旧账号未配置 protocol_config 时保留原地址与协议转换行为。原生 Ollama 单独配置。仅勾选服务实际支持的协议；供应商既有操作限制继续生效。

默认测试模型从已启用映射选择，可清空。连接测试通过 GET /models 检查上游模型是否存在，不产生生成调用；模型改名同步更新默认值，禁用或删除映射时清除默认值。模型列表不提供该模型时不能据此断言生成失败。

## 智能路由

对照[产品手册](https://docs.fit2cloud.com/ai-gateway/admin-user-manual/smart_route/)提供样本管理、决策日志、统计和路由规则。支持按行批量添加及CSV导入（可选阈值/备注列）、单样本阈值、显式构建队列、选中/全部构建、预览后添加样本。未构建或过期向量不参与匹配。

已就绪且版本有效的精确样本匹配属于本地规则，不请求向量服务；其余使用向量检索和既有失败策略。实际请求仅要求所选分支有兼容当前协议的可用模型。预览和真实决策分开记录，统计按标签、来源、模型和Token分布，失败包含决策失败和后续模型调用失败。新决策保存规范化请求文本（最多16000字符）、来源、分类置信差及命中样本文本摘要/阈值快照；历史缺失字段不推测填充。日志和详情仅管理员可访问。分类置信差为最高类别与另一类别的相似度差，不能当成概率。

## 模型供应商账号管理补全

提供协议类型（文本/文生图/向量）、账号/套餐类型、具体协议筛选、账号/模型搜索、可选显示列、模型映射搜索和发现结果批量补全。新增OpenAI向量、图片及重排独立路径，既有账号路径与凭据不改变；历史混合账号保留空分类，列表根据映射显示类型。每账号保留1至100条映射；类型不一致及删除路由引用的唯一向量映射被拒绝。

“连接检查”只读取模型列表；“测试”在确认费用后调用本账号已保存的单个/全部启用模型，记录真实用量、失败码和调用日志，不切换到其他账号。文本最多输出8 Token，向量使用短文本；图片需额外确认，保存时不会自动生成图片。保存后验证仅在管理员明确勾选时执行，失败不撤销已保存配置。按量/Coding/Token Plan不互相推断端点：已核对端点提供默认值，其余必须填写控制台服务地址。Gemini当前通过OpenAI兼容端点接入，不提供原生generateContent协议。

## 内容合规管理

对照[内容合规手册](https://docs.fit2cloud.com/ai-gateway/admin-user-manual/content_compliance/)提供四个标签：敏感词、审核样本、策略组、审核日志。敏感词可选择所属策略组、备注、启停、编辑、删除和按行批量导入；组/状态/关键词组合筛选。审核样本支持状态、备注、策略组和向量状态筛选、构建选中/全部向量。新增与文本修改不会自动构建；未构建、禁用、过期样本不参与检测。仅修改备注或状态保留有效向量。上游构建需明确确认可能产生费用。

策略组可先创建空组再添加资源，提供统一动作、风险等级、描述及启停。历史多策略引用和每条规则风险保留，不自动改变适用用户组/模型。已有引用的组不能删除；删除词或样本同步移除引用，历史审核证据不删除。关键词阻断在向量和目标模型调用前执行；语义检测可能使用共享向量服务。适用策略的通过、仅审计和拦截均记录审核日志；可按动作、风险、检测方式、策略组、Request ID/模型/证据和时间筛选。新日志保存规则文本、策略风险/阈值/描述快照及协议和审核阶段状态码，历史缺失字段明确标识，不回填猜测。审核状态码不是目标模型最终状态。

## 系统设置重设计

保留基础与品牌，新增基础设置、性能设置、向量服务、智能路由、内容合规与 Elasticsearch 标签。按标签保存运行配置，保留旧登录安全参数；乐观版本检查避免覆盖其他管理员保存。日志支持1至365天及历史366至3650天配置，用量汇总与管理审计不随调用日志过期清理。协议转换开关实际控制 Chat Completions / Anthropic Messages 转换，原生协议优先；Responses 仍需原生上游。

共享向量服务仅选择已启用且支持 Embeddings 的账号和映射；配置后路由与审核共用此账号。更换服务将标记旧样本失效，禁止自动付费重建，需显式构建。未配置时保持既有每路由向量模型与本地审核。低相似度/置信差不足回退简单组；真实调用错误继续遵循规则失败策略。内容合规总开关和可选全局阈值实际用于请求审核，空阈值保留原策略值。

Elasticsearch 支持9.x，API Key/Basic凭据加密保存、编辑留空保留，地址/认证范围变更须重填密钥。认证模型调用元数据和显式开启的脱敏正文写入专用 `helidata-gateway-calls` 索引；管理审计元数据写入独立 `helidata-gateway-audits` 索引，启用前记录不主动补传。外部正文上限各0至16KiB，0表示不保存；无认证头或密钥原文。Redis队列上限1000条/8MiB，满时丢弃新记录，失败重试并显示状态，更换URL丢弃旧目标记录。外部保留1至365天，清理仅针对本应用索引；服务器须授予该索引写入/删除权限。原PostgreSQL日志、用量及审计继续保留。当前生产无 Elasticsearch 服务配置，集成通过隔离模拟服务验收，真实服务需配置后测试。
