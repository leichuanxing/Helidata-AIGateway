# v1.0.7 发布记录

发布日期：2026-10-11。前后端版本、应用启动与离线部署配置统一为 v1.0.7，数据库迁移保持 0031。

## 功能与改进

- 新增网关安全：八个独立标签提供 IP / 后台 / API 访问控制、API Key IP 绑定、请求频率限制、登录安全、临时和永久封禁、可信代理、安全日志。支持分标签保存、草稿保留、地址校验与规范化、筛选、分页及详情；后台访问限制默认关闭，保存时防止管理员被自身规则锁定。
- 对话测试参数紧凑显示，默认输出 5000 Token，可调整至 65535；支持合计不超过 3 MiB 的多模态附件。
- 修复多模态内容合规处理：仅审核文字，非文本附件原样转发；完善审核样本原文匹配与虚拟模型合规链路。
- 系统设置显示时区使用下拉菜单，性能参数补充单位；智能路由与内容合规采用统一标签及页面样式。
- 重新整理 README，补充部署说明、使用限制、网关安全恢复方式及最新截图。

## 发布范围

标签 v1.0.7 与本次 main 分支发布提交一致。旧版离线镜像与安装包保持原版本；新包需依据 v1.0.7 源码重新构建，不将旧包改名为新版本。
