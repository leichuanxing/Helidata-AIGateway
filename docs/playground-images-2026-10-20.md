# 对话测试增加文生图模式

原因：原 `/api/admin/chat-test/models` 主动排除了 image 类型，页面仅实现 Chat Completions 和 SSE。此前供应商文生图能力可用，并不等同于对话测试已经具有生图界面。

## 实现

- 模型目录保留现有用户组授权和去重，增加文生图模型及文生图负载均衡路由，不展示向量/重排模型作为聊天模型。
- 选择图片模型后切换图片参数，默认一张、上游默认尺寸，可选最多四张和常用尺寸；实际支持以上游为准。不发送聊天历史、附件、系统提示词、温度、输出 Token 或流式参数。
- 新的精确管理入口 `/api/admin/chat-test/images` 只接收管理员会话，要求本次费用确认；复用原 `GatewayPipeline` 的授权、并发、路由、内容合规、计量和调用日志。公开 `/v1/images/generations` 仍仅接受 API Key。
- 图片结果支持 URL 和 PNG/JPEG/GIF/WebP Base64，大图预览、失败提示、停止等待、Request ID 日志及审核记录跳转。停止等待不代表上游没有生成或计费，不自动重试。
- 前端拒绝脚本地址、带账号密码的 URL、内嵌 SVG、不支持的图片格式和过大结果；页面不使用 HTML 注入展示供应商内容。远程图片使用 no-referrer；应用后端不代理下载图片，避免新增服务器抓取入口。
- CSP 仅将 img-src 增加 HTTP/HTTPS，以显示供应商图片 URL；script-src/connect-src 仍为 self，其余安全头保留。浏览器 HTTPS 环境的混合内容限制仍生效，不绕过证书检查。
- 费用确认放在输入区域，不随参数面板收起而隐藏；提交后清除确认。图片计数不伪装成 Token。

## 验证及边界

新增前端测试覆盖费用确认、无聊天参数、数量/尺寸边界、URL/Base64、脚本/SVG/凭证 URL 拒绝。新增后端测试覆盖目录 image 类型、管理员会话权限、公开 API Key 边界、请求校验及控制字段不外发；真实 HTTP 回归覆盖图片目录、费用拒绝、会话图片调用、合规阻断和响应审核头。

使用独立 PostgreSQL/Redis 和回环 HTTP 上游，没有挂载生产数据或发起真实付费生图。图像质量、真实供应商计费和每个模型的实际尺寸/数量组合未认证。HTTPS 配置不在本次范围。不推送 GitHub。
