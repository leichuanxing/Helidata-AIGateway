# 独立负载均衡路由

在“负载均衡路由”一级菜单管理独立路由组。模型组仍负责既有模型授权及顺序配置，本模块没有在模型组中增加调度配置。

## 创建和调用

1. 在“模型供应商”配置真实上游和模型映射。
2. 新增路由组，填写显示名称、唯一的统一模型名称和模型类型。
3. 在“模型节点”中选择现有供应商模型实例，独立设置权重、优先级、节点最大并发和启停状态。
4. 在“健康与故障切换”设置单次超时、最大重试次数、健康检查间隔、冷却时间和摘除阈值。
5. 客户端将现有 `/v1/*` 请求中的 `model` 改为统一模型名称。接口地址、API Key 和请求协议保持现有用法。

“全部模型”用户组可访问启用且存在可用节点的统一名称。指定模型授权的用户组，需将统一名称加入现有模型组并授权；这不会额外授予底层模型名称的直接调用权限。统一名称也显示在模型广场和对话测试中，标识为“负载均衡路由”。

统一模型名称及模型类型创建后不可更改，以避免静默改变客户端地址和权限关联；可编辑显示名称、策略、节点和其他运行配置。删除前需从模型组移除统一名称，历史调用日志保留。

## 五种策略

| 策略 | 行为 |
| --- | --- |
| 轮询 | 在可用节点之间轮流选择 |
| 加权轮询 | 平滑加权分配，权重范围 1–100 |
| 最少并发 | 选择当前占用请求数最少的节点 |
| 随机 | 随机选择可用节点 |
| 优先级路由 | 优先级数值小的节点优先，同优先级比较并发；高优先节点满载时可使用下一层 |

先使用可用的原生协议节点；只有没有可用原生协议节点时，才考虑已有适配器支持的转换路径。配置路由不能使上游获得其本身不支持的协议或模态能力。

各节点关联真实模型实例，不复制 API Key。一个供应商的多个模型映射可作为不同节点；节点权重、优先级、最大并发和启停仅影响当前路由，不修改供应商全局配置。

## 并发和故障切换

Redis 原子准入同时检查并预留全局、用户组、API Key、供应商、路由组及节点名额。节点上限、路由组上限及供应商全局上限同时生效。只有准入成功才推进轮询计数，排队轮询不影响分配比例。SSE 持续占用名额直到流关闭；租约续期失败会结束流并记录失败，避免失去资源名额后继续生成。

默认最多重试 2 次，可设 0–7 次，不含首次，同一请求不重复选择同一映射。路由单次超时用于普通请求和 SSE 建连，总期限仍受系统非流式超时约束。SSE 建连完成后使用既有空闲超时；响应交给客户端后不切换节点、不重放输出。

明确的连接建立失败、鉴权拒绝和限流可自动切换。读超时、上游 5xx 或异常响应不能证明上游未处理请求，默认不重试，可通过“允许处理结果不确定时重试”显式开启。该选项可能导致重复计费；通用上游 API 无法保证跨供应商恰好一次计费。明确未发送的失败释放预算，不确定结果继续按现有保守预算规则结算。

原有身份、模型授权、API Key/IP 绑定、限流、Token 配额及内容合规均继续生效。请求先检查统一名称的策略，选中节点后再检查对应底层逻辑模型的内容合规策略。路由配置发生变化时，排队及切换中的请求会重新校验版本，必要时返回 409 要求重试。

## 节点健康与恢复

- 推理失败达到阈值后节点进入冷却；鉴权拒绝或限流可立即冷却。
- 路由内故障状态独立，不因单个模型实例失败而停用供应商的其他模型。
- 冷却到期最多允许一个请求探测，成功后恢复正常容量。
- 后台按设定间隔检测，检查成功后恢复节点；自动探测与手动检测互斥，后台最多 4 个并行检查。
- 检查读取上游模型列表，不发起生成、不验证所有模型能力。上游不支持模型列表时不会仅因此错误摘除节点，应通过对话测试验证实际生成。
- 供应商自身的禁用、删除和全局健康限制仍生效。已删除/禁用映射不会被调度；类型已改变、不匹配的映射不会被调度。

## 监控与日志

运行监控展示节点健康、冷却时间、当前并发、供应商并发、请求量、成功率及平均响应时间，支持最近 1 小时、24 小时、7 天和每 10 秒刷新。无样本显示“—”。

统计严格按当前路由的节点 ID 汇总调用日志中的上游尝试，包含失败和客户端取消，不把其他路由共享节点的请求混入。SSE 响应时间为完整流时长，首 Token 延迟仍在调用日志中。流关闭后落库存在短暂延迟，统计范围受日志保留期影响。供应商并发包含其他业务占用。

调用详情展示路由组快照、策略、节点 ID、真实供应商/模型、重试次数、切换原因和错误码。统一模型名称保留在请求模型字段，实际逻辑模型和上游模型保留在对应字段。

## 部署兼容性

数据库迁移 `0032` 仅新增 `balanced_routes`、`balanced_nodes`，不改变模型组表，不重写原数据。首次上线前备份数据库、配置和 Provider 主密钥，在数据副本执行升级并确认健康，再安排容器替换。降级会删除新增路由配置，不能当作无损回退。

本模块直接服务统一模型名称；不提供“路由指向另一虚拟路由”的嵌套功能。节点只允许真实供应商映射，避免递归和权限混淆。
