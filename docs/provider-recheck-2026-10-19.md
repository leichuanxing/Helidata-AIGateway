# 模型供应商完整流程复查与优化

## 问题及处理

| 优先级 | 问题 | 修复 |
| --- | --- | --- |
| P2 | 重排序账号在详情页新增映射时，默认类型是文本，还可选不兼容的向量类型 | 详情页和账号抽屉共用模型类型规则，重排默认并限定为 rerank |
| P2 | 批量模型测试离开页面后仍可能继续启动后续计费调用 | 增加停止测试；组件卸载或弹窗关闭时取消 HTTP 请求并阻止后续调度，保留已完成结果 |
| P3 | 映射修改、停用、删除后，详情页默认测试模型和账号数据未同步 | 映射操作完成后刷新账号信息，不重置当前详情标签 |
| P3 | 草稿和已保存账号的发现入口校验细节及错误提示不同 | 共用模型列表校验与安全错误文案，区分鉴权、地域/空间权限、超时、网络、接口不存在及格式错误 |
| P3 | 供应商目录未加载时即可打开新增账号，可能使用宽泛的临时默认协议 | 目录加载前禁用新增入口 |

## 检查范围

- 20 个供应商及其账号套餐的保存、读取与协议预设；自定义供应商协议选择、专用协议地址、私有代理地址保留。
- 新增/编辑账号、名称复用、Key 保留/更换及跨供应商保护、连接检查、草稿/已保存账号发现模型、阿里云原生分页。
- 模型映射新增、编辑、禁用、删除、最后一条映射保护、重排类型限制；默认测试模型随映射重命名、禁用和删除的同步。
- 测试模型的费用确认、图像独立确认、配置版本/管理员权限变动后停止；前端批量测试进行中取消和结果之间停止。
- 供应商与负载均衡节点、目录、授权、内容合规、并发及调用日志的既有集成回归。
- 账号详情、筛选、状态与健康展示、启停、删除，以及接口权限和密钥不出现在公开响应中的边界。

## 测试方法及边界

后端在独立容器中使用真实 Nginx、FastAPI、PostgreSQL、Redis、HTTPX 运行回归；上游使用本地可控 HTTP 服务。批量取消测试也使用真实 HTTP 连接，确认取消正在进行的请求或在结果间停止后，不会调用下一个模型。没有进行商业供应商计费生成请求。

停止操作会取消网关 HTTP 连接并阻止后续模型调用；已发送给供应商的当前请求仍可能已产生费用，不能承诺撤销上游计费。

## 部署

保持数据库 0033，不修改业务账号、Key 和模型映射。部署前备份数据库与完整持久化目录，保留原容器和回滚路径。保持原端口及数据挂载，不推送 GitHub。
