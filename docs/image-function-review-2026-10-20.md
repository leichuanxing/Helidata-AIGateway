# 文生图功能检查与修复

## 发现的问题

1. **删除后重建被旧类型拦截。** 生产只读查询确认 `qwen-image-3.0-pro` 的逻辑目录仍为 text；唯一历史映射属于已删除账号 139，映射及账号均已软删除，没有模型组引用。新 image 映射被旧目录类型拒绝。
2. **图片测试超时链路不一致。** 原管理端测试整体 150 秒、浏览器 170 秒、Nginx 180 秒，不能遵循性能设置中最长 600 秒的非流式上游超时。
3. **空白提示词未拦截。** 原 min_length 不能阻止全空格文生图提示词，可能把无效请求发送上游。

## 修复

- 在现有逻辑模型一致性检查中处理无引用旧记录：没有未删除账号映射、模型组、负载节点、智能路由向量或共享向量配置引用时，可按新映射的真实类型重新使用名称。禁用账号仍属于有效配置，不能借此绕过类型保护；不修改历史软删除映射或调用日志。
- 文本、向量、重排、图片之间仍不能覆盖正在使用的模型类型。实际冲突错误包含模型名及已有类型，并提示调整引用或使用独立请求名称。
- 测试任务按“队列超时 + 非流式超时 + 30 秒收尾”限制；浏览器保留手动取消，由服务端控制时限，Nginx 测试路由覆盖该配置最大值。未修改生产性能参数。
- 全空白图片提示词在转发前返回 422。
- 阿里云接入提示补充地域及业务空间地址、同步非流式、图片 URL 等限制。没有擅自更换用户 API 地址或密钥。

## 接口范围

当前网关文生图入口为 `/v1/images/generations`，使用 `openai-images`，复用供应商映射、API Key/用户组授权、并发、内容合规、调用日志及用量。保存账号、发现模型及连接检查不生成图片；管理端真实图片测试必须另行确认费用。通用聊天测试不是图片生成工作台。异步任务、multipart 编辑、mask 等不属于本次新增范围。

阿里云官方文档：[千问图像生成与编辑](https://help.aliyun.com/en/model-studio/qwen-image-generation-and-editing-api-reference)。OpenAI 兼容生图应使用控制台对应地域和业务空间的 `/compatible-mode/v1` 基础地址；图片计数及尺寸不能伪装成 Token 用量。真实供应商模型、地域权限及费用仍需按账户控制台核实。

真实供应商生图和实际图像质量未执行，未消耗本轮生成费用。HTTPS 不在本次处理范围，不推送 GitHub。
