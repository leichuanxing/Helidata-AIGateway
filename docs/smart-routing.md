# 智能路由使用说明

总开关控制整体服务，每条规则独立使用本地/向量或模型决策。旧功能配置地址重定向至路由规则。模式选择位于规则编辑页，不进行全局批量切换。

## 本地/向量

配置共享Embedding模型、简单组、复杂组及阈值，添加代表性样本并显式构建。就绪计数同时检查样本状态、修订版本、向量代次及模型；过期数据不能参与分类。精确匹配就绪样本无需额外向量请求，其他文本通过Embedding相似度检索。

Top K限制检索样本；相似度阈值决定样本是否参与判定，单样本阈值优先；分类置信差衡量两类最高有效相似度的差，不是概率。无样本或判定不足转简单组；向量服务异常按失败策略处理。编辑携带版本可防止旧内容覆盖新内容，构建状态变化也可能要求重新打开样本。

## 模型决策

支持TypeSafe/jev-latest和阿里云百炼/decision-model-preview。阿里云填写完整HTTPS接口地址，包括/systemone。密钥加密保存，留空保留当前供应商已有密钥，更换供应商不会借用其他供应商密钥。

配置2–10个目标、不同目标模型组、适用及排除说明、兜底组、决策超时及置信度下限。模型的目标概率与独立置信度含义不同；选择其他、低置信度或服务异常转兜底，安全与配额拒绝不会绕过。

“测试模型”验证真实连通及响应格式，固定测试数据仍可能产生用量；“决策预览”用于评估实际问题的分类，保存配置本身不产生调用。测试会使用当前输入的地址和密钥，注意不要将问题发送至不可信服务。

## 授权、证据及边界

用户组需要授权虚拟模型及当前模式的全部目标和兜底组；向量模式还需Embedding授权。目标组须启用，存在兼容当前操作的真实模型，不允许递归虚拟模型。实际请求经过原有认证、限流、配额和内容合规，既检查虚拟模型也检查真实目标。

预览与实际请求分别计数，记录来源、命中目标、耗时、原因和证据快照；历史说明不随当前配置变化。父生成请求与决策/向量子调用独立记用量，Token未知不估算为0。

智能路由使用文本输入，多模态请使用明确的逻辑模型。模型分类可能误判或受输入干扰，不能作为权限边界。应使用代表性和边界问题验收；要获得能力/成本分层，目标组需要实际不同的底层模型。未配置、未构建或旧样本无法实现预期分流。
