# 模型供应商复查与自动协议配置

参考：[账号池管理文档](https://docs.fit2cloud.com/ai-gateway/admin-user-manual/account_pool/)。文档保留协议选择，本轮按用户的明确要求改为普通供应商自动选择、自定义供应商手动选择；保留此前增加的多模态类别和默认测试模型。

## 本轮调整

- 普通供应商：根据供应商、套餐和模型类别自动匹配支持的协议，只读展示标签、鉴权和分协议地址，不再提供协议下拉选择。
- 自定义供应商 Custom OpenAI：保留协议多选、独立服务地址及 Anthropic 鉴权方式选择。
- 新增或切换供应商、套餐、模型类别、服务地址时重新计算配置；服务地址带尾斜杠仍能识别官方端点，使用自定义主地址时不意外发送到官方协议地址。
- 编辑历史账号时保留保存的协议、URL、路径前缀和鉴权，不因修改备注、优先级等字段自动改写连接配置。主动切换连接条件后重新匹配。
- 切换供应商时，前后端均阻止自动沿用旧供应商 Key；需显式更换或清除。模型发现也执行相同保护，避免把原凭据误发送到新供应商。
- 列表状态切换带配置版本，避免旧页面覆盖其他管理员的修改；请求模型名提交前检查格式。
- 账号改为禁用时自动取消“保存后验证”，避免验证选项被禁用后仍勾选、导致保存无法完成。
- 模型批量测试改为逐模型请求并显示进度、保留已完成结果；无启用映射时显示提示。测试请求增加独立的 180 秒代理等待窗口，覆盖单模型最长 150 秒的服务端保护。更新实际运行时 Nginx 模板，非仅修改未使用的静态配置。

## 功能检查

新增、编辑、删除、同名重建、启停及版本冲突、筛选与显示列、模型映射、默认测试模型、模型发现、连接检查、单模型与多模型测试、失败结果和调用日志已检查。真实供应商的模型支持范围仍以所选服务与模型为准；不能以参考产品支持的原生接口代替本系统实际适配的协议。

保留安全差异：保存后真实调用仍为显式可选，不默认发起可能计费的调用；文生图需额外确认。模型发现不产生生成请求，发现接口不可用时仍可手工添加映射。

## 验证与边界

- 后端完整 101 项通过；20 个供应商、39 个账号类型按自动协议配置逐个实际 HTTP 保存与读取，独立 URL、鉴权、字段值一致，非法参数及过期配置版本被拒绝。
- 前端类型检查及生产构建通过，21 项 Node 回归通过，覆盖自动协议类别、套餐覆盖和独立服务地址。
- 真实 Nginx、应用、PostgreSQL、Redis，加本地测试上游：模型发现、连接检查、测试同意、批量生成结果、调用日志、上游 401、删除及跨供应商 Key 防误用通过。该上游是测试夹具，不是供应商实测，不产生费用。
- 慢响应测试先复现 504，定位实际运行配置与静态配置差异后修复模板；重新执行 61 秒的真实本地 HTTP 慢响应成功，完整流程 62.588 秒通过。此项检验代理等待机制，不证明真实供应商的生成能力。
- 不使用真实供应商 Key 做生成测试；没有执行所有供应商收费调用。既有账号的连接内容不自动修改。

无需数据库迁移，版本保留 v1.0.7，不推送 GitHub。
