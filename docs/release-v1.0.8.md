## 主要变化

- 供应商默认服务地址、图标、套餐及协议预设；普通供应商自动匹配协议，自部署及自定义供应商支持手动选择Chat Completions、Responses、Anthropic Messages。
- 供应商编辑保留既有连接配置，切换供应商需显式更换或清除原Key；批量模型测试显示进度并改善代理超时。
- 对话测试双栏卡片对齐、参数表单统一、附件与消息显示优化；保留5000 Token默认输出上限和3 MiB附件总限额。
- 用户模型广场正确展示及筛选多模态模型。
- SSE转发允许合法的error:null字段，真实错误继续阻断并脱敏；新增4项回归测试。
- README、前后端版本及启动/离线构建工具统一为v1.0.8。
