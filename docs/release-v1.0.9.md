# v1.0.9 发布说明

发布日期：2026-10-23。数据库迁移：0036。

## 主要变化

- 智能路由新增TypeSafe、阿里云百炼模型决策；阿里云支持自定义HTTPS决策地址、加密密钥、可用性测试及预览。每条规则独立选择本地/向量或模型决策，模式切换保留参数、密钥和样本。
- 完善向量样本导入、构建与重试、版本匹配、就绪提示及编辑冲突保护；修复规则列表隐藏、辅助接口故障时空列表及统计目标名称显示。
- 决策日志保存目标概率、独立置信度、原始选择及说明快照，区分预览/真实调用，统计父请求与子调用的用量边界。
- 合规配置独立归入内容合规模块，智能路由总开关置于本模块；系统设置统一运行参数、备份及管理审计，优化加载和保存。
- 包含此前概览、用量、调用日志、模型授权联动、供应商及负载均衡流程修复和启停脚本改进。
- 前后端及启动/离线构建元数据更新为1.0.9，离线迁移检查更新为0036。README和六张应用截图更新。

## 验证

发布前同日后端隔离回归179项：177通过、2项条件跳过；其中独立模式测试在专用环境另行通过，另一个跳过项为文生图超长响应专项。前端57项、TypeScript及构建通过。两轮真实模拟验证当前配置供应商的路由决策、向量构建、精确匹配、语义检索、Chat/Responses/Messages普通和流式转发、日志关联及统计对账。

两轮真实调用结果不代表所有模型能力、分类准确率、外部供应商或长时间稳定性。用量测试仍出现待定位的asyncio transport告警；生产破坏性故障和长期压力未验证。
