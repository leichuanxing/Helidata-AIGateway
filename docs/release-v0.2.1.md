# v0.2.1 前端布局与交互优化

发布日期：2026-10-07（北京时间）。数据库版本仍为0028。

## 显示与布局

- 管理后台、用户中心共用统一的页面间距、侧栏、顶部导航、筛选栏、表格、分页、标签、空状态和表单样式。
- 弹窗和抽屉的正文独立滚动，底部操作区保持可见；窄屏表单标签在控件上方，筛选控件和配置表单按屏幕宽度排列。
- 个人设置采用资料和账号安全分区；模型卡片提供悬停与键盘焦点反馈；系统配置分区和状态说明保持清晰。
- 用量趋势采用平滑曲线，保留数据点明细联动；较长的统计口径可展开查看。
- 公共运行状态页使用当前品牌，不再显示开发阶段；说明检查范围，提供返回工作台入口。

## 交互

页面切换使用短暂淡入与轻微位移；路由加载条根据实际路由状态显示，页面提供aria-busy状态。侧栏、标签页、按钮、输入框和反馈控件使用统一动画节奏，并支持prefers-reduced-motion。查询参数变化保留当前页面实例；页面路径变化重新进入相应页面，未更改后端业务权限与调用逻辑。

## 验证

前端vue-tsc和Vite生产构建通过；检查27个主要页面及子页面，包括列表/详情、路由、合规、统计、配置、运维、用户中心、登录和服务状态。系统设置7个分区、版本弹窗、浅色/深色主题、桌面和窄屏新增账号抽屉均完成可视检查。430像素宽度检查供应商、用户、调用日志、系统设置、模型广场和个人设置，未出现页面横向溢出。浏览器验收期间未发现前端错误或警告。
