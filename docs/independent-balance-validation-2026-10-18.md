# 独立负载均衡路由检查报告

日期：2026-10-18。基于 v1.0.8，新增独立一级菜单，不修改原模型组结构；版本和 Git 标签保持不变。

## 已实现

- 路由组新增、编辑、删除，统一模型名称关联现有供应商模型实例，不复制密钥。
- 轮询、平滑加权轮询、最少并发、随机、优先级路由；节点权重、优先级、并发及启停独立配置。
- Redis 原子预留供应商、节点、路由组等并发额度，租约续期、释放与客户端断开清理。
- 节点异常摘除、冷却探测、后台健康恢复及手动连接检查。
- 限制重试次数和单次超时；默认不重试处理结果不确定的失败。SSE 开始输出后不切换节点。
- 运行监控显示节点及供应商并发、请求数、成功率、平均响应时间和故障状态。
- 调用日志记录路由组、策略、节点、重试次数及切换原因；复用授权、配额、限流和内容合规。

## 升级与边界

- 数据库迁移仅新增两张独立表；降级会删除新路由配置，应先导出或备份。生产升级前应备份数据库、配置及主密钥，保留旧镜像，安排短时重启并健康检查。
- 上游模型列表检查只能验证连接及鉴权；不支持模型列表的服务仍需单独验证生成能力。
- 上游处理后断连可能已计费，网关无法保证外部服务恰好执行一次；默认关闭不确定结果重试。
- 监控按已落库尝试统计，受日志保留期影响。尚未进行长时间压力、Redis 故障集群及全部供应商实测。
- 本次未替换生产容器、未修改生产数据、未推送 GitHub。候选镜像和测试日志保留在服务器独立开发目录中。
